# Anti-School-Micro

Тумблер на горячую клавишу, который превращает любой микрофон в максимально громкий, перегруженный и неразборчивый. Повторное нажатие возвращает всё как было.

Цепочка обработки:

1. компрессор (порог −30 дБ, 20:1, +24 дБ) — тихий фон поднимается до уровня голоса
2. усиление ×300 и срез по потолку
3. fuzz-перегруз
4. бас +15 дБ (180 Гц) и режущие частоты +15 дБ (3 кГц)
5. ещё ×20 и срез
6. bitcrusher: 4 бита, 6 кГц

В итоге и голос, и фоновый шум прижаты к 0 dBFS.

Микрофон от этого не портится: вся обработка идёт в компьютере, после микрофона. Работает с любым микрофоном — USB, встроенным, гарнитурой.

## Linux (Arch / Artix)

### Установка

```sh
sudo pacman -S pipewire pipewire-pulse wireplumber swh-plugins libnotify
git clone https://github.com/fedyaqq34356/Anti-School-Micro.git
cd Anti-School-Micro/linux
chmod +x mic-boost.sh
```

На Artix (без systemd) PipeWire должен быть запущен в сессии. Если его нет, добавь в автозапуск своего WM/DE:

```sh
pipewire &
pipewire-pulse &
wireplumber &
```

Проверка: `pactl info` должен показать `Server Name: PulseAudio (on PipeWire …)`.

### Запуск

```sh
./mic-boost.sh    # включить
./mic-boost.sh    # выключить
```

При включении скрипт берёт текущий микрофон по умолчанию, ставит его на 100%, запускает виртуальный микрофон **Mic BOOST** и делает его микрофоном по умолчанию. При выключении фильтр закрывается, а микрофон и его громкость возвращаются.

### Горячая клавиша

Hyprland (`hyprland.conf`):

```
bind = SUPER CTRL, M, exec, /путь/к/Anti-School-Micro/linux/mic-boost.sh
```

Sway / i3:

```
bindsym Mod4+Ctrl+m exec /путь/к/Anti-School-Micro/linux/mic-boost.sh
```

KDE / GNOME: Параметры → Клавиатура → Свои сочетания клавиш, команда — путь к `mic-boost.sh`.

### В программах

В Discord, Telegram, OBS и т. д. выбери микрофон **«По умолчанию»** или **«Mic BOOST»**. Если там выбран конкретный микрофон, фильтр до программы не дойдёт.

### Настройка

Цепочка лежит в `linux/mic-boost-chain.conf`. Можно менять, например:

- `"Mult" = 300.0` / `"Mult" = 20.0` — сила перегруза
- `"Bit depth" = 4.0`, `"Sample rate (Hz)" = 6000.0` — насколько «битый» звук
- `"Gain"` у `bass` / `harsh` — бас и резкость

Свой файл цепочки можно подсунуть через `MIC_BOOST_CHAIN=/путь/к/файлу.conf`.

## Windows 10

### 1. Виртуальный кабель

Скачай и установи **VB-CABLE** (бесплатно): https://vb-audio.com/Cable/

Распакуй архив → правой кнопкой по `VBCABLE_Setup_x64.exe` → **Запуск от имени администратора** → **Install Driver** → перезагрузи ПК.

После этого в системе появятся устройства **CABLE Input** и **CABLE Output**.

### 2. Python

Скачай Python 3.12 с https://www.python.org/downloads/windows/ и при установке обязательно отметь **Add python.exe to PATH**.

### 3. Программа

Скачай репозиторий (**Code → Download ZIP** или `git clone`), открой папку `windows` и в адресной строке проводника набери `cmd` → Enter. В открывшемся окне:

```bat
pip install -r requirements.txt
```

### 4. Запуск

Двойной клик по **`run.bat`**. В окне будет видно, какой микрофон используется.

- **Ctrl + Win + M** — включить/выключить BOOST (короткий высокий писк — включён, низкий — выключен)
- **Enter** в окне — то же самое
- закрыть окно — выключить программу

Пока программа работает, звук с микрофона всегда идёт в CABLE. Когда BOOST выключен, звук идёт без изменений.

### 5. В программах

В Discord, Telegram, OBS и т. д. в качестве микрофона выбери **CABLE Output (VB-Audio Virtual Cable)**.

Микрофон Windows по умолчанию **не трогай**: он должен остаться твоим настоящим микрофоном, программа берёт звук с него.

### Если взялся не тот микрофон

```bat
python mic_boost.py --list
```

покажет устройства с номерами. Запусти с нужным номером микрофона:

```bat
python mic_boost.py --input 3
```

Чтобы не набирать это каждый раз, допиши номер в `run.bat`: `python mic_boost.py --input 3 %*`.

### Другие параметры

```bat
python mic_boost.py --on                  # сразу включить BOOST
python mic_boost.py --hotkey "ctrl+alt+b" # другая горячая клавиша
```

### Автозапуск без окна

`Win + R` → `shell:startup` → Enter. В открывшуюся папку положи ярлык на **`run-hidden.bat`**. Программа будет стартовать вместе с Windows в фоне, переключать — по Ctrl + Win + M.

### Если горячая клавиша не срабатывает в игре

Игра запущена от администратора, а программа — нет. Запусти `run.bat` тоже от имени администратора.

## Почему в звонке может быть тише

В Telegram, Discord, Zoom и других программах для звонков есть шумоподавление и автогромкость, и они приглушают такой звук. Выключи их в настройках звука программы: в Discord это **Шумоподавление**, **Эхоподавление** и **Автоматическая регулировка усиления**.
